# ADR-008 — Licence MIT

## Contexte

Le site doit être disponible librement sur le GitHub de l'utilisateur (dépôt `pid-game`). Jusqu'au commit `1dc5f7e`, le dépôt n'avait pas de licence (signalement de D-002).

## Décision

- Licence MIT, titulaire lucashg7892 (décision D12 du registre).
- Texte dans le fichier `LICENSE` à la racine, ajouté par le commit `bf7fd65`.
- La police manuscrite prévue sera sous licence OFL, avec sa propre licence copiée dans `public/fonts/` (décision D10) : Prévu.

## Conséquences

- Chacun peut réutiliser, modifier et redistribuer le code, à condition de conserver la notice de copyright et la licence.
- Aucune garantie n'est donnée.
- Les dépendances npm gardent leurs propres licences.

## Statut

Accepté (décision de l'utilisateur ; 2026-11-12).
